# Crawlit Presentation

Slidev deck for Japanese meetup talk.

## Setup

```bash
cd presentation
npm install
npm run dev
```

Opens `http://localhost:7777`.

## Export

```bash
npm run build         # static SPA → dist/
npm run export        # PDF (needs playwright-chromium)
```

## Edit

All slides live in `slides.md`. Markdown + Vue components.

Slidev docs: https://sli.dev
